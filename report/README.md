# ChalkBox report bundle

This folder contains the report source, generation tooling, and evidence index for Omnikon National Hackathon 2026.

- [`../output/pdf/ChalkBox_Final_Technical_Report.pdf`](../output/pdf/ChalkBox_Final_Technical_Report.pdf) — submission-ready product and implementation report.
- `../scripts/build-technical-report.py` — reproducible ReportLab source for the PDF.
- `evidence/` — CI, browser, Lighthouse, and screenshot evidence added after final hosted verification.

The working prototype and GitHub repository are the final-round deliverables. The report is supplementary and designed to make architecture, responsible AI, free-tier constraints, and verification easy to inspect.
