# Product screenshots

Build once, run the verified production preview in one terminal, then capture the standard evidence set from a second terminal:

```bash
pnpm build
pnpm preview
```

```bash
pnpm screenshots
```

Set `CHALKBOX_SCREENSHOT_URL` to capture from the final deployed origin instead. Expected outputs are:

1. landing;
2. Quick Brief;
3. lesson editor;
4. private Classroom Mode;
5. learner-safe Present Mode;
6. Quick Check 2.0 tally;
7. assessment bank;
8. mobile Classroom Mode.

The same eight files are generated by the desktop and mobile Playwright projects in GitHub Actions and uploaded as the `chalkbox-product-screenshots` workflow artifact.
